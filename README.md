# Dessert Finder App

다이어터 및 당뇨인을 위한 저당 디저트/글루텐프리/비건 매장 검색 앱입니다.

주요 기능
- 오프라인 매장 검색 (서울 구/동 중심)
- 온라인 택배 전문 매장 검색 (전국)
- 카테고리 필터: 저당 디저트, 글루텐프리, 저당+글루텐프리, 비건
- 오프라인 매장 중 택배 가능 여부 표시
- 매장 기본 정보: 매장명, 주소, 영업시간, 메뉴, 가격

실행 방법
1. npm install
2. npx expo start
3. iOS/Android 에뮬레이터 또는 Expo Go로 실행

프로젝트 구조
- App.js: 메인 화면
- src/data/mockData.js: 샘플 데이터
- src/screens: 홈/오프라인/온라인 화면
- src/components: 재사용 컴포넌트
